# Free access and operating costs

Supreme Canine Academy is currently free to use. The owner's policy is to keep the hosted app free unless operating costs make a change necessary.

The current public app runs its library lookup and dog profiles in the visitor's browser. No paid AI service, account requirement, subscription, checkout, or payment processing is enabled. The optional backend scaffold stays disabled by default.

If hosting, bandwidth, storage, or optional services begin to create costs, the maintainer may revisit how those costs are covered. Any future funding or pricing change should be explained publicly before it is implemented. This is a current access policy, not a promise that every future hosted service will remain free forever.

The open-source software license is separate from the hosted-service policy. Existing MIT-licensed code remains available under its license, and people may run their own copies. Self-hosting infrastructure and optional external services may have their own costs.

Repository CI uses standard GitHub-hosted runners for a public repository. It contains no scheduled jobs, production deploys, cloud credentials, or paid external API calls. No automatic charges or paid features are enabled by this project.
