READ BEFORE USING

Privacy & safety

Local data

Dog profiles are stored in this browser only. Questions, answers, and session setup are not stored. Sign-in is optional and disabled in the default local-review configuration. No analytics, telemetry, or model API is used.

Optional hosted account

When an owner configures Firebase, sign-in uses the official Firebase SDK with in-memory session persistence. Creating an account can store only username, email, pending/active access state, and creation time in the Academy account summary. It does not track questions, sessions, dogs, or sign-in activity. Hosted answers require separate consent for each question and send only the question.

Draft content

The 67 lesson records are review drafts; none is approved for production. A matching citation points to that draft, not to independent validation.

Health and safety

This tool cannot diagnose or prescribe, set medication doses, or replace a veterinarian or qualified behavior professional. Urgent signs or possible toxin exposure need urgent veterinary advice. Limited keyword routing may miss or misclassify situations.

Training cues

YES releases and promises a treat. GOOD maintains position; reward later. NO stops unwanted behavior. NOPE is a distinct playful retry or adjustment cue. OKAY is a general release. Positional cues hold until release or another command. This app does not infer force or correction intensity.
