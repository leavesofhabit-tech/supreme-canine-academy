# Public review corpus

`knowledge.json` is the sanitized reader payload already used by the public app. It contains 67 records and zero production-eligible records. Its source text and review labels were preserved for this public-source release.

The repository does not include private source bundles, provenance registries, original `KnowledgeCorpus.json` files, or customer/profile data. The validator accepts only the current reader fields and rejects private provenance markers.

To propose a correction, identify the record ID, describe the change, and provide accessible supporting sources. Preserve clinical/referral boundaries and avoid copying third-party articles. Changing public copyright permissions does not change a record's review, rights-clearance, or backend eligibility state.
